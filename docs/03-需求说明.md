# arbin-aperix-geo — 需求说明

本文档描述 **Aperix AI**（工程名 `arbin-aperix-geo`）的需求原则、用户场景、功能需求、非功能需求与约束。

**文档索引**：[README.md](./README.md)

## 1. 需求原则

1. **单地域主线**：默认 **中国大陆**；不以「多国家区域矩阵」为核心卖点。
2. **双主体平等**：**域名** 与 **品牌关键词** 均为一级监测主体。
3. **指标诚实**：品牌主体拆分 **提及** 与 **登记 URL 被引用**；六大 KPI 释义与 [06-分析指标.md](./06-分析指标.md) 一致。
4. **合规优先**：采样、存储、展示、生成内容遵守法规与模型平台条款；不提供操纵排序的灰黑产能力。
5. **可演进**：MVP 跑通四步流水线；04b 策略（机会、搜索加权、AEO 报告）按 V1 交付。

### 1.1 品牌分析四步流水线（官方命名）

| 步 | 英文 | 主标题 | 副标题（摘要） |
|----|------|--------|----------------|
| 01 | `verify` | 品牌信息验证 | 资产合规校验与提示词多维裂变 |
| 02 | `dispatch` | 大模型任务调度 | 大陆主流模型联网通道并发唤醒 |
| 03 | `clean` | 语义清洗降噪 | 大模型文本废话剔除与结构化提取 |
| 04 | `analyze` | 声量聚合诊断 | 全网搜索基数加权与可视化策略输出 |

- **04a（P0）**：六大 KPI 看板 — 见 §6、[06-分析指标.md](./06-分析指标.md)  
- **04b（V1+）**：搜索基数校准、机会、AEO/Word 报告 — 见 [04-功能清单.md](./04-功能清单.md) §6  

流程详情：[05-诊断流程.md](./05-诊断流程.md)

## 2. 关键用户场景（User Stories）

| ID | 角色 | 目标 | 主要覆盖步骤 |
|----|------|------|--------------|
| US-1 | 无官网品牌负责人 | 品类问句下是否提到我、相对竞品排第几 | Verify + Analysis（提及、排名、情感） |
| US-2 | 有官网 B2B 负责人 | 引用率与竞品域名差异 | Verify + Analysis（引用率、引用下钻） |
| US-3 | 代运营 | 多主体切换、分客户汇报 | 平台层 + Analysis |
| US-4 | 增长负责人 | 周会关键信号与优先行动 | Analysis 04b（V1） |

### US-1 无官网品牌负责人

**验收**：品牌主体 + 竞品品牌词；概述页 **可见度、平均排名、情感** 可用；无「必须主域」阻塞。

### US-2 有官网的 B2B 市场负责人

**验收**：域名主体 **引用率**、URL 下钻；竞品含域名与品牌；报告含引用分布（V1 导出）。

### US-3 代运营

**验收**：多主体列表与隔离；V1 可增强成员权限。

### US-4 增长负责人周会

**验收**：V1 关键信号与行动列表；推送渠道分期。

## 5. 约束与假设

1. **模型能力**：联网、引用、输出结构因平台而异；Analysis 需 **渠道口径说明**。
2. **品牌歧义**：依赖类目/排除词与规则；允许人工标注样本。
3. **信源与社媒**：符合平台规则与法律；部分能力从客户链接列表 + 手动起步。
4. **无独立站**：不承诺等同 SEO 域名权威；承诺监测与可归因建议路径。
5. **04b 副标题**：搜索基数加权、AEO 报告等为 **V1+**，MVP 不阻塞四步闭环。

## 6. 六大核心指标（需求层）

归属 **04 Analysis · 04a**。算法公式、API 字段、实现状态见 **[06-分析指标.md](./06-分析指标.md)**。

| 指标 | API 字段 | 需求层含义（共用） |
|------|----------|-------------------|
| **可见度** | `visibility_rate` | 成功回复中 **至少提及一次** 自有品牌的比例 |
| **AI 提及** | `mention_intensity` | 正文中提及自有品牌的 **强度**（频次/条均次数） |
| **声量份额** | `share_voice` | 自有与竞品 **提及次数** 占比（非仅「提及条数」） |
| **平均排名** | `average_rank` | 回答正文中按首次出现排序的 **平均顺位**（越小越好） |
| **引用率** | `citation_rate` | **在提及前提下** 含指向自有域名链接的比例（品牌主体见登记 URL） |
| **情感倾向** | `sentiment_score` | **提及品牌片段** 的情感得分（越高越正面） |

### 6.1 按主体类型的展示差异

| 指标 | 域名主体 | 品牌关键词主体 |
|------|----------|----------------|
| 可见度 | 品牌名/域名在回答中出现 | 规范名或别名出现 |
| AI 提及 | 同上，按次数 | 同上 |
| 声量份额 | 与配置竞品集合对比 | 同左 |
| 平均排名 | 与竞品在正文中的出现顺序 | 同左 |
| 引用率 | 己方 **根域** 出现在链接主机 | **登记 URL** 被引用；另列提及率 |
| 情感倾向 | 提及己方时的态度 | 同左 |

- 地域：**仅中国大陆**。
