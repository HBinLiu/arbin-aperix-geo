## 1. SheepGeo — 公开文档侧优点（摘要）

| 维度 | 优点（可借鉴） |
|------|----------------|
| **本土化叙事** | 面向大陆 AI 搜索语境（秘塔、Kimi、文心等），与 Aperix 定位一致。 |
| **网站分析闭环** | 爬站 → 多模型可见性 → **SHEEP 五维** + **GEM** → **llms.txt** 专项 → **CWV** → 长流程报告与阶段进度。 |
| **评分可解释** | 五维（语义 / 可信 / 结构化 / 生态 / 性能）+ 等级带（A+～D）与**优化优先级**叙事，利于销售与交付。 |
| **关键词渗透** | 「轮询词生成 → 全模型交叉检测 → 渗透率/首位/模型分布」产品化清晰；**配额公式**、**任务不可取消**等规则写进文档，利于工程与运营对齐。 |
| **竞品分析** | 区域、行业模板、细分赛道、多维度轮询词与**对比矩阵**；与「关键词渗透」数据在报告中心打通。 |
| **报告中心** | 多数据源勾选、**Word** 导出、章节开关（SWOT / 行动计划 / 市场概述）、可选 **AI 撰写**；与配额档位挂钩。 |
| **运维与爬站** | Bot/WAF 放行说明、分析前准备、频率建议等**可执行运营文档**，降低交付摩擦。 |

**局限（对标时需注意）**：`/developer` 自动化抓取正文弱；部分子页（如品牌监控）需人工补全。

## 2. Dageno.ai — 官网与 Open API 侧优点（摘要）

| 维度 | 优点（可借鉴） |
|------|----------------|
| **产品叙事** | **See → Understand → Act** 三章结构（监控 / 归因理解 / 内容与行动），降低「只有仪表盘」的感知。 |
| **监控颗粒度** | 强调 **多区域热力**（官网写 252+ 区域）、**多模型同时追踪**（示例含 ChatGPT、Gemini、Perplexity 等）；Aperix 可收敛为 **大陆省/场景模板** 而非全球 252。 |
| **归因深度** | **引用率**、**提及频率**、**地理分布**、**竞品对比**；理解章突出 **信源域排名**、**引用路径深度**、**竞品内容份额** — 与「引用≠信任」故事线一致。 |
| **行动闭环** | **提示词优化**、**内容缺口**、**知识库加固**；并承诺 **可部署级内容生成**（Agent + 规模化），与机会/智能体模块对齐。 |
| **商业化与交付** | 定价与「轻量工具 / 企业平台」对比表、**快速上手**、**2h 人工响应 SLA** 等（部分属运营承诺，功能清单可单列「服务等级」）。 |
| **开放能力** | **原生 API**（`x-api-key`、统一 JSON、分页、`/business/api/v1/...` 形态）+ **MCP** 与 Claude/Cursor/n8n 等生态叙事；利于 Aperix **X1** 与集成故事。 |
| **Agency** | **白标**、**Agency 控制台** 作为差异化卖点；可映射 V2 渠道场景。 |

**局限**：官网偏**全球/英文营销**；大陆模型与合规需 Aperix 自行定义，不可照搬区域数与模型列表。

**前端实现（对标记录，非对方官方声明）**：营销站 HTML 可见 **Next.js App Router**（`/_next/static/...`、`app/[locale]/...` 分包）。图表库：团队确认对方产品界面使用 **Recharts**。**Aperix 前端已定**为 **Vite + React + Tailwind + shadcn/ui + Recharts**（控制台为 SPA，与对方 Next 营销站技术形态不同，图表选型对齐）。

## 3. 二者互补 — 写入本项目的「合并优点」清单

以下作为 **Aperix AI** 在功能规划上可吸收的「长板组合」，已在 `04-功能清单.md` 中拆为 **§9（SheepGeo 增量）** 与 **§10（Dageno 增量）**，并避免重复已有条目的可合并进后续评审。

| 合并能力 | SheepGeo 侧来源 | Dageno 侧来源 | 建议归属（见功能清单） |
|----------|-----------------|---------------|-------------------------|
| **整站 + 评分 + llms.txt + 性能** | 网站分析、SHEEP、CWV、llms.txt | 快速诊断、GEO vs SEO 叙事 | §13 W* |
| **多模型 × 多提示词 × 配额** | 关键词渗透、竞品任务公式 | 多模型实时监测 | §3 D*、§13 K* |
| **引用 / 信源 / 竞品份额** | 报告与渗透结果中的 URL/品牌 | 理解章：域排名、路径深度、竞品内容份额 | §5 N*、§14 DG* |
| **监控 → 理解 → 行动 IA** | 文档枢纽「功能选择」 | See / Understand / Act | §14 DG1、§8 G* |
| **报告与 AI 叙述** | Word、多数据源、SWOT | 诊断报告、Agent 内容 | §9 R*、§13 R3–R4 |
| **开放与自动化** | 开发者页待补 | API + MCP | §13 X1、§14 DG5 |
| **渠道与白标** | — | Agency、白标 | §10 M3、§14 DG6 |
