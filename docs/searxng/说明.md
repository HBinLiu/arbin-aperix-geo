# SearXNG（Docker Compose）

本目录存放 [SearXNG 官方 container 模板](https://docs.searxng.org/admin/installation-docker.html)，供本地或内网部署元搜索引擎，后续可替代/补充竞品发现中的百度搜索。

## 文件说明

| 文件 | 说明 |
|------|------|
| `docker-compose.yml` | 官方模板（`core` + `valkey`） |
| `.env.example` | 环境变量示例，复制为 `.env` 后修改 |
| `core-config/settings.yml` | 运行配置（首次需自行创建，见下） |

## 快速启动

```bash
cd docs/searxng
cp .env.example .env
# 编辑 .env（端口、镜像版本等）

# 最小 settings（生产请更换 secret_key）
cp core-config/settings.yml.example core-config/settings.yml

docker compose up -d
```

浏览器访问：http://localhost:8080（默认端口，见 `.env` 中 `SEARXNG_PORT`）。

JSON 搜索 API 示例（bang 限定单引擎）：

```text
GET http://localhost:8080/search?q=关键词&format=json&language=zh-CN
GET http://localhost:8080/search?q=!bd+关键词&format=json    # 百度
GET http://localhost:8080/search?q=!sogou+关键词&format=json
```

## 调大单次返回条数

SearXNG **没有**单独的「全局 50 条」开关；JSON 里 `results` 长度 = 各引擎结果合并去重后的数量。要接近后端 `COMPETITOR_SEARCH_PAGE_SIZE=50`，需在 **`core-config/settings.yml`** 里给每个启用的引擎加 `number_of_results`（见 `settings.yml.example`）。

```bash
# Docker 部署（本目录）
vim core-config/settings.yml   # 在 baidu / sogou / 360search / quark 下加 number_of_results: 50
docker compose restart core
```

```bash
# 验证（原始条数应明显上升，仍可能 <50，取决于引擎是否支持）
curl -sG 'http://127.0.0.1:8080/search' \
  --data-urlencode 'q=跨境药品直购' \
  --data-urlencode 'format=json' \
  --data-urlencode 'language=zh-CN' \
  | python3 -c "import sys,json; print(len(json.load(sys.stdin).get('results',[])))"
```

远程实例（如 `http://47.94.192.165:8061`）：在服务器上编辑挂载的 `/etc/searxng/settings.yml`（或 `SEARXNG_SETTINGS_PATH` 指向的文件），同样为各引擎设置 `number_of_results: 50` 后 **重启 SearXNG 容器/进程**。

可选：`search.max_page: 2` 让支持翻页的引擎多取一页（与后端「换 query」策略不同，那是 API 的 `pageno`）。

## 关闭境外引擎（国内 VPS 必做）

`use_default_settings: true` 时，官方默认仍会启用 brave、startpage、google 等。必须在 **`core-config/settings.yml`** 里对每个引擎写 `disabled: true` 才能关掉（见 `settings.yml.example` 顶部注释与 `engines` 列表）。

```bash
cp core-config/settings.yml.example core-config/settings.yml
# 编辑 engines：境外项保持 disabled: true；国内项按需开启
docker compose restart core
```

不关境外引擎时：单次搜索常多等约 **10s/引擎超时**，日志出现 `ConnectTimeout`、`engine timeout`，对竞品发现几乎无收益。

## 国内搜索引擎

示例见 `core-config/settings.yml.example`：启用 baidu / sogou / 360search（可只开 360），并关闭 google / bing / brave / startpage / wikidata 等。

| 引擎 | shortcut | 说明 |
|------|----------|------|
| baidu | `bd` | 网页 |
| sogou | `sogou` | 网页 |
| 360search | `360so` | 网页 |
| quark | `qk` | 夸克 |

聚合搜索（多国内引擎同时查）：省略 bang，例如 `q=关键词&format=json`。

**注意：**

1. 百度等易触发 CAPTCHA，实例宜部署在国内且控制请求频率。
2. **Aperix 竞品发现**：`searxng.py` 仅通过 SearXNG JSON API 搜索（须配置 `SEARXNG_BASE_URL`，不传 `engines`）。

**后端调用示例：**

```http
GET {SEARXNG_BASE_URL}/search?q=行业+竞品+官网&format=json&language=zh-CN
```

Aperix 请求**不传** `engines`，使用实例 `settings.yml` 里启用的引擎。若 `原始条数=0`，请在 SearXNG 侧关闭境外引擎并启用国内源。

## 更新官方模板

```bash
cd docs/searxng
docker compose down
curl -fsSLO \
  https://raw.githubusercontent.com/searxng/searxng/master/container/docker-compose.yml \
  https://raw.githubusercontent.com/searxng/searxng/master/container/.env.example
docker compose pull
docker compose up -d
```
