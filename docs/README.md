## 四步与六大指标（速查）

### 诊断四步

| 步 | 英文 | 主标题 | 产出 |
|----|------|--------|------|
| 01 | `verify` | 品牌信息验证 | 主体、竞品、主题、已确认提示词 |
| 02 | `dispatch` | 大模型任务调度 | `raw_text`、采样作业状态 |
| 03 | `clean` | 语义清洗降噪 | `parsed`（结构化信号） |
| 04 | `analyze` | 声量聚合诊断 | KPI、图表、报告与机会（后两者 V1+） |

### 看板六大指标（04 Analysis · 04a）

| 产品名 | API 字段 |
|--------|----------|
| 可见度 | `visibility_rate` |
| AI 提及 | `mention_intensity` |
| 声量份额 | `share_voice` |
| 平均排名 | `average_rank` |
| 引用率 | `citation_rate` |
| 情感倾向 | `sentiment_score` |

公式见 [06-分析指标.md](./06-分析指标.md)。
