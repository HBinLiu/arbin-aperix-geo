# arbin-aperix-geo — 项目说明

**文档索引**：[README.md](./README.md)

## 1. 项目名称与含义

- **工程/仓库名**：`arbin-aperix-geo`
- **产品名（工作名）**：**Aperix AI**
- **GEO**：Generative Engine Optimization — 面向大模型回答、AI 摘要/推荐、带引用的生成式搜索等场景的可见度与影响力优化。

## 2. 背景与机会

海外 GEO 产品（如 Dageno.ai）多以 **网站域名** 为核心。中国大陆差异：

1. **模型与入口**：国产大模型（豆包、通义、文心、Kimi、DeepSeek 等）需合规、稳定接入。
2. **客户结构**：大量客户 **无独立官网**，品牌分散在电商、社媒。
3. **地域策略**：聚焦 **中国大陆**，不做全球多区域矩阵。

## 3. 产品定位（一句话）

当用户在大陆主流 AI 场景提问时，帮助团队回答：**有没有被看见、排在哪里、情感和信源如何、相对竞品声量如何、下一步做什么** —— 通过 **四步分析流水线** 持续监测与诊断。

## 4. 目标用户

| 类型 | 典型诉求 | 关注指标（示例） |
|------|----------|------------------|
| B2B / SaaS | 品类推荐、文档被引用 | 可见度、引用率、平均排名 |
| 消费品牌 / 电商 | 大促场景曝光 | 可见度、声量份额、情感 |
| 无独立站客户 | 品牌词监测 | 可见度、AI 提及、平均排名 |
| 代运营 | 多客户汇报 | 全指标 + 分主体 |

## 5. 范围声明

### 5.1 In Scope

- **双主体**：域名主体、品牌关键词主体（别名、消歧）。
- **四步流水线**：[05-诊断流程.md](./05-诊断流程.md)  
  `Verify` → `Dispatch` → `Clean` → `Analysis`
- **六大 KPI**：[06-分析指标.md](./06-分析指标.md)（Analysis · 04a）
- 周期性采样、竞品对比、机会与报告（04b，V1+）。
- 中文 UI、企业基础能力（权限、日志等，分期）。

### 5.2 Out of Scope

- 全球多区域热力矩阵（非主线）。
- 非合规获取模型输出。
- 保证排名 / 刷量类灰黑产能力。

## 6. 监测主体模型

### 6.1 域名主体（Site Subject）

- **输入**：主域、站点元数据。
- **指标侧重**：**引用率**、URL/主机分布、外链机会。

### 6.2 品牌关键词主体（Brand Subject）

- **输入**：规范品牌名、别名、类目消歧。
- **指标侧重**：可见度、AI 提及、声量份额、排名、情感；引用率基于 **登记落地页**（可选）。

### 6.3 多主体

- 租户下多个主体；报表与任务必须绑定 **当前主体**。

## 7. 术语表

| 术语 | 说明 |
|------|------|
| Verify / Dispatch / Clean / Analysis | 官方四步，见 [05-诊断流程.md](./05-诊断流程.md) |
| 提示词 / Prompt | 可重复执行的监测问句 |
| 主题 / Topic | 业务场景聚合（如「MES 选型」） |
| **可见度** | 回复中至少提及一次自有品牌的比例（`visibility_rate`） |
| **AI 提及** | 提及频次强度（`mention_intensity`） |
| **声量份额** | 相对竞品的提及次数占比（`share_of_voice`） |
| **平均排名** | 正文中提及顺位均值，越小越好（`average_rank`） |
| **引用率** | 提及场景下含自有域名链接的比例（`citation_rate`） |
| **情感倾向** | 提及品牌时的态度得分（`sentiment_score`） |
| `parsed` | Clean 阶段写入的结构化 JSON，Analysis 的唯一聚合输入 |
