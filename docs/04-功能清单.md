# arbin-aperix-geo — 功能清单

本文档列出 **Aperix AI** 拟交付的功能，按 **官方四步流水线** 与 **平台层** 组织，并按 **MVP / V1 / V2** 分期。验收口径以 [03-需求说明.md](./03-需求说明.md)、[05-诊断流程.md](./05-诊断流程.md)、[06-分析指标.md](./06-分析指标.md) 为准。

**文档索引**：[README.md](./README.md)

---

## 0. 分期与对标

### 0.1 分期定义

| 分期 | 目标 |
|------|------|
| **MVP** | 四步跑通：Verify 配置 → Dispatch 采样 → Clean 解析 → Analysis 六大 KPI 看板 |
| **V1** | 04b 策略（机会、报告）、多模型/调度增强、权限、搜索基数校准（可选） |
| **V2** | 智能体、开放 API、白标、效果追踪等 |

### 0.2 竞品参考

| 资源 | 说明 |
|------|------|
| [02-竞品对标.md](./02-竞品对标.md) | SheepGeo / Dageno 能力长表 |

竞品能力映射到本清单 **§9–§10**（增量附录），主线仍以 **§2–§7** 四步为准。

## 8. 依赖关系

```text
平台层（§1）
    │
01 Verify（§2）──► 02 Dispatch（§3）──► 03 Clean（§4）──► 04 Analysis
                                                              ├─ §5 六大 KPI / 看板
                                                              └─ §6 机会 / 报告（V1+）
```

周期监测：**§3 Dispatch** 与 **§4–§5** 按调度重复执行，无需重跑 Verify（除非改提示词库）。
